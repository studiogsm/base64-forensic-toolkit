# Base64 Forensic Toolkit v2.7

Professional forensic tool for iOS analysis, Base64 decoding, PIN recovery and digital evidence processing.

## Features
- Base64 PIN Parser (4/6 digit)
- SQLite Scanner (from ZIP/FFS)
- iOS Artifact Extractor (sms.db, KnowledgeC, CallHistory)
- Keychain Decoder (GrayKey)
- JWT Analyzer
- Entropy Analysis
- BFU/AFU Checker
- Lockdown Certificates Parser
- Hash Identifier (24 types)
- PIN Dictionary Generator
- Birthday Dictionary Generator
- Leet Speak Generator
- Password Strength Analyzer
- Dictionary Deduplicator
- Timestamp Converter (Unix/Apple/Windows/Chrome)
- URL/URI Decoder
- Hex Viewer
- PDF Report Generator
